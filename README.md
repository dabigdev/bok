# Phi — Face Proportion Calculator

A small, dependency-free calculator for comparing selected facial measurements
with the golden ratio (φ ≈ 1.618). Enter all measurements using the same unit,
then choose **Calculate proportions** to see each ratio and its percentage
difference from φ.

Open `index.html` in a browser to use it. No installation or build step is
required.

The comparisons are for mathematical exploration only, not a measure of beauty,
health, or personal worth.
